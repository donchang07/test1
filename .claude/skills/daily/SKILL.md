# daily

사용자가 자유롭게 적은 문장을 그날의 데일리 노트로 정리합니다.

## 절차

1. 오늘 날짜(YYYY-MM-DD)와 요일을 확인합니다(`date +%F`, 요일은 한국어 한 글자: 월·화·수·목·금·토·일).
2. 입력을 두 갈래로 나눕니다.
   - **작업**: 해야 할 일, 밀린 일, 만들 것. 쉼표·"·"·"," 등으로 묶인 항목은 하나씩 쪼개고, 간결한 명사형으로 다듬습니다(예: "ontology 자료" → "Ontology 자료 정리").
   - **메모**: 감정, 생각, 계획, 그 밖의 기록. 사용자의 표현을 최대한 그대로 둡니다.
   - 애매하면 메모로 둡니다. 없는 내용을 지어내지 않습니다.
3. `daily/YYYY-MM-DD.md`를 확인합니다.
   - 없으면 아래 형식으로 새로 만듭니다.
   - 있으면 기존 내용을 지우지 않고, 해당 섹션 끝에 새 항목만 덧붙입니다(같은 항목은 중복 추가하지 않음). "완료", "끝냈다" 같은 말이 기존 작업을 가리키면 그 체크박스를 `- [x]`로 바꿉니다.
4. git 저장소라면 `Add daily note for YYYY-MM-DD`(갱신이면 `Update daily note for YYYY-MM-DD`)로 커밋하고, 지정된 작업 브랜치에 푸시합니다.
5. 사용자에게 저장된 노트 내용을 짧게 보여 줍니다.

## 형식

```markdown
# YYYY-MM-DD (요일) 데일리 노트

## 밀린 작업
- [ ] 항목

## 메모
- 항목
```

해당 내용이 없는 섹션은 생략합니다.
